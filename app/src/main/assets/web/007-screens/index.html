使用教程
1在 GitHub 新建一个 私有仓库（例如 vault-backup），留空初始化即可。
2生成令牌：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens，仓库范围只选上面那个私有仓库，权限只勾 Contents: Read and write。
3回到本页粘贴令牌 → 点「识别令牌」，App 会自动列出你的仓库，点击选择（没有可点「新建私有仓库」），再点「保存配置」（令牌只存本机，绝不上传）。
4点「立即备份到 GitHub」—— 数据在本地加密成 .fvault 后再上传，主密码不会离开本机。
5换手机或重装后：识别令牌 → 选同一个仓库 → 点「从云端恢复」，输入备份密码即可还原。
⚠️ 只上传加密后的 .fvault；令牌泄露请立刻到 GitHub 撤销
